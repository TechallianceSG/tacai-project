# tactokyomail

`tactokyomail` is the planning workspace for the proposed TAC Tokyo Mail project.

Primary direction:

- Internal-use email service for TAC operations.
- AI platform integration for controlled system email workflows.
- Email accounts and lifecycle management for dispatched / expatriate / onboarding employees.
- Preserve existing mature `tacjob.com` email operations unchanged.
