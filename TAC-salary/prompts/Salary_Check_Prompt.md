# Salary Check Prompt Draft

Use later for AI-assisted payroll review. AI output is advisory only and must not replace payroll compliance validation.

## Prompt

You are reviewing a monthly salary record for payroll operations. Check for missing fields, unusual allowance/deduction values, negative net salary, mismatched country/currency, and status inconsistencies.

Return:

1. Summary
2. Potential issues
3. Questions for payroll operator
4. Suggested next action

Do not invent statutory rates. If rate validation is required, ask for the official rule source and effective date.
