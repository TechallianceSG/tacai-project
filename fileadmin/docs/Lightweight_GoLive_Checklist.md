# FileAdmin 轻量化上线 Checklist

Last updated: 2026-06-23

## 1. 上线前 P0 必须完成

- [ ] 文档记录登记、同一记录多文件上传、附件级描述、版本查看可用。
- [ ] 合同到期提醒列表可用。
- [ ] 审计日志 append-only 可用。
- [ ] 文件不能被覆盖；新版本必须新增记录。
- [ ] 文件不能物理删除；只能归档。
- [ ] 至少完成 10 个真实/脱敏文件试录入。
- [ ] 明确 MVP 不上传 My Number、银行账号、护照等高敏个人资料。
- [ ] 确认备份方式：至少手动备份 `database/` 和 `attachments/`。

## 2. 上线前 P1 建议完成

- [ ] User_admin 登录集成。
- [ ] Portal 模块入口。
- [ ] Entity scope 过滤。
- [ ] CSV 导出。
- [ ] 当前有效模板视图。
- [ ] 文件大小限制。
- [ ] 上传文件类型白名单。
- [ ] 下载审计。

## 3. 业务 UAT 用例

| 用例 | 期望结果 |
|---|---|
| 新增派遣客户基本契约 | 文件台账显示合同，状态 active |
| 同一合同记录上传多个文件 | 每个附件都有独立标题、说明、类型、版本、签署状态 |
| 上传第二版合同 | 历史版本仍可见，当前版本正确切换 |
| 设置合同 60 天提醒 | Reminders 页面出现对应提醒 |
| 归档旧模板 | 模板不再作为当前有效版本显示 |
| 下载合同文件 | 审计日志记录下载行为 |
| 修改合同到期日 | 审计日志保留 before/after |
| 尝试物理删除 | 系统不提供物理删除入口 |

## 4. 试运行会议建议

参与人：

- 业务负责人 / Consulting Manager
- HR / 派遣合规负责人
- Finance
- IT/System Admin
- 文书模板负责人

确认事项：

- 文件分类是否符合当前业务。
- 合同提醒天数是否足够。
- 对外模板版本规则是否可执行。
- 保密等级是否清楚。
- 真实文件录入工作量是否可接受。

## 5. 第一阶段运营规则

1. 所有客户合同必须录入 FileAdmin。
2. 对外正式模板必须从 FileAdmin 当前有效模板下载。
3. 合同续约/终止必须在提醒记录中留下处理结果。
4. 旧版本只读保留，不允许覆盖。
5. 高敏个人资料暂不进入 FileAdmin，等待专门安全设计。

## 6. 备份建议

每日或每周手动备份：

```text
fileadmin/database/
fileadmin/attachments/
fileadmin/audit/
```

备份命名：

```text
fileadmin_backup_YYYYMMDD.zip
```

至少保留：

- 最近 7 天每日备份。
- 最近 3 个月每月备份。
- 重要上线前备份永久保留。
