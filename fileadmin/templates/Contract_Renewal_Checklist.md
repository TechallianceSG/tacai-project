- 业务线：派遣 / 猎头 / RPO / IT 服务 / 供应商 / 其他
- 当前负责人：
- 合同开始日：
- 合同结束日：
- 自动更新：有 / 无 / 不明
- 终止通知期限：
- 下次提醒日：

## 续约前确认

- [ ] 客户/供应商合作是否继续？
- [ ] 单价/费率/付款条件是否需要调整？
- [ ] 服务范围是否变更？
- [ ] 派遣/IT 服务工作地点、工作内容、契约形态是否有变化？
- [ ] 是否需要法务/社労士/外部专家确认？
- [ ] 是否涉及个人信息、再委托、保密条款更新？
- [ ] 是否需要开票/付款模块更新 master data？
