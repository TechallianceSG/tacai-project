# FileAdmin 文件编号规则

Last updated: 2026-06-23

## 1. 文件资产编号

格式：

```text
FA-YYYY-NNNN
```

示例：

```text
FA-2026-0001
```

## 2. 合同编号

格式：

```text
CT-业务线-YYYY-NNNN
```

业务线代码：

- DISP：派遣
- REC：猎头/人材紹介
- RPO：RPO
- IT：IT 服务/SES/外包
- VEN：供应商/外包伙伴
- CORP：公司通用

示例：

```text
CT-DISP-2026-0001
CT-REC-2026-0002
CT-IT-2026-0003
```

## 3. 模板编号

格式：

```text
TPL-业务线-语言-YYYY-NNNN
```

语言代码：

- JA：日文
- EN：英文
- ZH：中文

示例：

```text
TPL-DISP-JA-2026-0001
TPL-REC-EN-2026-0002
```

## 4. 版本号规则

- `v1.0`：初版正式发布。
- `v1.1`：小修改，如文字、格式、联系人变更。
- `v2.0`：重大条款、业务逻辑、法务内容变更。

## 5. 禁止事项

- 禁止用文件名本身作为唯一编号。
- 禁止覆盖旧版本文件。
- 禁止手工重复使用已经分配的编号。
