# FileAdmin 文件管理系统

FileAdmin 是计划中的轻量级企业文件管理系统，面向日本派遣、人材紹介/猎头、RPO、IT 服务中小企业。

## 业务目标

- 管理客户合同、派遣基本契约、个别契约、NDA、报价/注文书、交付物、对外文书、公司模板与内部审批文件。
- 对客户合同、派遣契约、外包/IT 服务合同设置到期提醒、续约提醒、自动更新条款提醒。
- 对公司对外文书进行版本管理，保留历史版本、变更原因、发布状态、适用语言和负责人。
- 建立面向日本合规场景的文件台账、权限、审计、保存期限和检索机制。
- 先以本地轻量 MVP 上线，后续再接入 TACAI Portal、User_admin、客户主数据、EmployeeAdmin、Billing、Timesheet 等模块。

## 初始目录结构

```text
fileadmin/
├── backend/                # 后续 Python 标准库 Web App
├── frontend/               # 预留静态资源或未来前端
├── database/               # 本地 JSON 数据库
├── attachments/            # 实际上传文件；按业务分类/年月/记录编号存放
├── templates/              # 公司对外文书模板、编号规则、合同检查清单
├── audit/                  # 审计导出/只读审计辅助文件
├── docs/                   # 设计、计划、数据 schema、SOP
├── prompts/                # 后续 AI/OCR/摘要/条款抽取提示词
├── i18n/                   # 日英中标签
├── memory/                 # 本模块活动记忆
└── archive/                # 超过 100KB 的历史记忆/文件管理归档摘要
```

## 轻量化上线原则

1. **先台账，后流程**：MVP 先解决“文件在哪里、谁负责、何时到期、当前版本是什么”。
2. **先人工审核，后 AI 自动化**：OCR/AI 摘要只能生成草稿，合同要点、到期日、客户名、金额等必须由负责人确认。
3. **先本地 JSON，后数据库**：与现有 TACAI MVP 保持一致，先用 Python 标准库 + JSON 文件快速上线。
4. **先权限隔离，后外部共享**：第一阶段仅内部 HR/Finance/Admin/Consultant Manager 使用，不开放客户外部入口。
5. **所有关键变更必须审计**：文件登记、版本上传、状态变更、到期提醒、下载/查看权限变更都要写 append-only audit log。

## 推荐本地端口

- 建议 FileAdmin 使用 `8011`，避免与当前 TACAI `8000-8009` 和临时 gateway `8010` 冲突。
